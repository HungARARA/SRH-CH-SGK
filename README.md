# SRH CH SGK – Chuẩn hoá kiến thức Sâu Răng Học (SGK)

🌐 **Trang web để học:** https://hungarara.github.io/SRH-CH-SGK/

Mỗi bài trong giáo trình Sâu Răng Học (ĐH Y Dược Cần Thơ) được làm thành **1 file `.html`** để học. File mở bằng trình duyệt, không cần mạng, và gồm:
- giải thích dễ hiểu theo đúng mục SGK, có hộp 🔍 "Vì sao…?" giải thích cơ chế;
- sơ đồ, mẹo nhớ, bẫy đề;
- nút "Che từ khoá";
- trắc nghiệm tự kiểm tra.

- **Học:** mở trang web ở trên (điện thoại hay máy tính đều được), hoặc tải về rồi mở file `Bài N - <tên bài>.html`.
- **Soạn bài mới:** làm theo `QUY TRÌNH CHUẨN HOÁ.md`.
- **Nội dung:** nằm ở `nguon/Bài N.md`, dựng thành `.html` bằng `nguon/build.py`. Script cũng dựng lại `index.html` (trang chủ của trang web). Push lên nhánh `main` thì trang web tự cập nhật sau khoảng 1 phút.
